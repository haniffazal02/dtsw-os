## 🚀 Getting Started (3 Steps)

**Step 1: Install**
```bash
npm install
```

**Step 2: Setup**
```bash
node setup-dirs.js
```

**Step 3: Run**
```bash
npm run dev
```

**Then**: Copy layout/page example files to proper route group folders
